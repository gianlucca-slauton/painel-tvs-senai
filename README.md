# 📺 Painel de TV SENAI — Sistema de Gerenciamento de Conteúdo (CMS)

> Sistema web desenvolvido para administrar e transmitir conteúdos dinâmicos (avisos, horários, eventos e comunicados) nas TVs das unidades do **SENAI**.

---

## 📌 Sobre o Projeto

Este projeto consiste em uma plataforma de gerenciamento centralizado para os painéis e telas digitais espalhados pela instituição. Com ele, administradores e professores podem agendar, atualizar e controlar em tempo real o que é exibido em cada TV do SENAI.

### 🎯 Principais Funcionalidades
- **Painel Administrativo:** Interface intuitiva para publicação e agendamento de conteúdos (banners, vídeos, avisos).
- **Gestão de Telas/TVs:** Vinculação e organização das TVs por bloco, sala ou setor da unidade.
- **Modo Exibição (Player):** Interface otimizada e responsiva para rodar diretamente nas Smart TVs ou dispositivos acoplados (Chromecast, Raspberry Pi, etc.).
- **Atualização em Tempo Real:** Atualizações instantâneas de comunicados e alertas urgentes sem necessidade de reiniciar as TVs.

---

## 🛠️ Tecnologias Utilizadas

- **Front-end:** HTML5, CSS3, JavaScript / React (ou o framework utilizado)
- **Back-end:** Node.js / Python / PHP (ou a linguagem do servidor)
- **Banco de Dados:** PostgreSQL / MySQL / MongoDB
- **Autenticação:** JWT / Sessions para controle de acesso dos administradores
